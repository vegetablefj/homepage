Definition 1.1 Category and basic notation.

A category \(\mathcal C\) consists of the following data.
🔗
  1. A set \(\Ob(\mathcal C)\) of objects and, for each ordered pair of objects \(X,Y\text{,}\) a set \(\Hom_{\mathcal C}(X,Y)\) of morphisms or arrows from \(X\) to \(Y\text{.}\)
    🔗
    🔗
  2. For every object \(X\text{,}\) an identity arrow \(\id_X\in\Hom_{\mathcal C}(X,X)\text{,}\) and for every three objects a composition map
    \begin{equation*} \Hom_{\mathcal C}(Y,Z)\times\Hom_{\mathcal C}(X,Y)\longrightarrow\Hom_{\mathcal C}(X,Z),\qquad (g,f)\longmapsto gf. \end{equation*}
    These maps satisfy \(\id_Yf=f=f\id_X\) and \(h(gf)=(hg)f\) whenever the arrows have the indicated consecutive endpoints.
    🔗
    🔗
🔗
We write \(X\in\mathcal C\) for \(X\in\Ob(\mathcal C)\text{.}\) The set of all typed arrows is
\begin{equation*} \Ar(\mathcal C)=\coprod_{(X,Y)\in\Ob(\mathcal C)^2}\Hom_{\mathcal C}(X,Y). \end{equation*}
The endomorphism set is \(\End_{\mathcal C}(X)=\Hom_{\mathcal C}(X,X)\text{;}\) its composition and identity make it a monoid.
