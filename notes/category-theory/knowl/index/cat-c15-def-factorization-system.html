Definition 15.9 Orthogonal factorization system.

For a collection \(\mathcal M\) of arrows, let \({}^\perp\mathcal M\) be all arrows orthogonal on the left to every member of \(\mathcal M\text{;}\) define \(\mathcal E^\perp\) dually. An orthogonal factorization system is a pair \((\mathcal E,\mathcal M)\) such that
\begin{equation*} \mathcal E={}^\perp\mathcal M,\qquad \mathcal M=\mathcal E^\perp, \end{equation*}
and every arrow admits a factorization \(f=me\) with \(e\in\mathcal E\text{,}\) \(m\in\mathcal M\text{.}\)
