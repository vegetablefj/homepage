Definition 15.20 Enough projectives and injectives.

The category has enough \(\mathcal E\)-projectives if every object \(X\) admits an arrow \(P\to X\) in \(\mathcal E\) with \(P\) \(\mathcal E\)-projective. It has enough \(\mathcal M\)-injectives if every \(X\) admits an arrow \(X\to I\) in \(\mathcal M\) with \(I\) \(\mathcal M\)-injective. Unqualified enough projectives and enough injectives use all epimorphisms and all monomorphisms, respectively; enough regular projectives uses regular epimorphisms.
