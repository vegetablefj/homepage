Definition 6.7 Filtered, cofiltered, and directed.

A category \(I\) is filtered if it satisfies all three conditions:
🔗
  1. It has at least one object.
    🔗
    🔗
  2. For any \(i,j\in I\text{,}\) there are an object \(k\) and arrows \(i\to k\text{,}\) \(j\to k\text{.}\)
    🔗
    🔗
  3. For any parallel arrows \(a,b:i\to j\text{,}\) there is an arrow \(c:j\to k\) with \(ca=cb\text{.}\)
    🔗
    🔗
🔗
It is cofiltered if \(I^\op\) is filtered. A filtered diagram in these notes is a diagram whose indexing category is filtered. A directed poset is a nonempty poset in which every pair of elements has a common upper bound; regarded as a category, it is filtered.
