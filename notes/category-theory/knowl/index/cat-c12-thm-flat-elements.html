Theorem 12.3.

A presheaf \(P\) belongs to \(\operatorname{Ind}(\mathcal C)\) if and only if \(\operatorname{el}(P)\) is filtered. These presheaves are also called flat presheaves. Their canonical filtered presentation is
\begin{equation*} P\cong\operatorname{colim}_{(c,x)\in\operatorname{el}(P)}h_c. \end{equation*}
For any filtered presentation \(P\cong\operatorname{colim}_{i\in I}h_{X_i}\text{,}\) its cocone defines a final functor \(I\to\operatorname{el}(P)\text{.}\)
🔗
🔗

Proof.
Suppose first that the filtered presentation is given. Evaluation gives \(P(c)\cong\operatorname{colim}_i\Hom(c,X_i)\text{.}\) Some stage exists, so its identity arrow supplies an element of some \(P(X_i)\text{;}\) hence the element category is nonempty. For two element objects \((c,x)\text{,}\) \((d,y)\text{,}\) represent their elements by arrows \(c\to X_i\) and \(d\to X_j\text{.}\) Pass to a common later stage \(k\text{.}\) Its cocone element in \(P(X_k)\text{,}\) together with these two arrows, is a common receiving object in the element category.
🔗
Now take parallel arrows \(f,g:(c,x)\rightrightarrows(d,y)\text{.}\) Represent \(y\) by \(v:d\to X_i\text{.}\) The equality \(P(f)(y)=P(g)(y)\) says that \(vf\) and \(vg\) have the same class in the filtered colimit of \(\Hom(c,X_i)\text{.}\) The same-stage equality criterion gives an arrow \(i\to k\) after which these maps agree. The resulting arrow \(d\to X_k\) is a morphism from \((d,y)\) to a cocone element, and equalizes \(f,g\text{.}\) This proves filteredness.
🔗
Write \(x_i\in P(X_i)\) for the element corresponding by Yoneda to the presentation map \(h_{X_i}\to P\text{.}\) Cocone compatibility defines \(j:I\to\operatorname{el}(P)\text{,}\) \(i\mapsto(X_i,x_i)\text{.}\) For a fixed \((c,x)\text{,}\) objects of \(((c,x)\downarrow j)\) are representatives \(c\to X_i\) of \(x\text{.}\) Such representatives exist. Any two become equal at a common later stage, so they map to one common representative in this comma category. It is therefore nonempty and connected, proving that \(j\) is final.
🔗
Conversely, the density theorem presents every presheaf as the displayed colimit over its element category, using the maps corresponding to the elements. If this category is filtered, it is an allowed small filtered presentation. Thus \(P\) is an Ind object.
