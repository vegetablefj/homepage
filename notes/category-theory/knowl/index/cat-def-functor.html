Definition 1.8 Functor and comparison properties.

For categories \(\mathcal C,\mathcal D\text{,}\) a functor \(F:\mathcal C\to\mathcal D\) assigns an object \(FX\) to each \(X\) and a function
\begin{equation*} F_{X,Y}:\Hom_{\mathcal C}(X,Y)\longrightarrow\Hom_{\mathcal D}(FX,FY) \end{equation*}
to each pair, such that \(F(\id_X)=\id_{FX}\) and \(F(gf)=F(g)F(f)\text{.}\) When its direction is clear, this is also called a covariant functor.
🔗
  1. It is faithful if every \(F_{X,Y}\) is injective, full if every \(F_{X,Y}\) is surjective, and fully faithful if all these functions are bijective.
    🔗
    🔗
  2. It is essentially surjective if each object of \(\mathcal D\) is isomorphic to some \(FX\text{.}\) It is conservative if \(F(f)\) being invertible always implies that \(f\) is invertible.
    🔗
    🔗
  3. Its essential image is the full subcategory of \(\mathcal D\) on all objects isomorphic to some \(FX\text{.}\) In particular it is replete: it contains every ambient object isomorphic to one of its objects. Its arrows are all ambient arrows between the chosen objects, not only arrows in the image of \(F\text{.}\)
    🔗
    🔗
  4. A contravariant functor from \(\mathcal C\) to \(\mathcal D\) means a functor \(\mathcal C^{\mathrm{op}}\to\mathcal D\text{.}\) Thus it assigns to \(f:X\to Y\) an arrow \(F(f):FY\to FX\text{,}\) with \(F(gf)=F(f)F(g)\text{.}\)
    🔗
    🔗
