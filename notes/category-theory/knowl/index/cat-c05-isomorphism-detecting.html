A different condition on a family \((G_s)\) is that a map \(f:X\to Y\) must be invertible whenever every \(\Hom(G_s,f)\) is bijective. We call this an isomorphism-detecting family. The corrected definition of a system of generators in [KS06, Definition 5.2.1(i), as corrected in the author's errata, item (ii), page 2] uses this condition. It should not be substituted for our separating condition without checking the hypotheses of the result being used.
