An arrow \(t:T\to X\) is called a generalized element of \(X\) of shape \(T\text{.}\) Precomposition changes its shape, and a map \(u:X\to Y\) sends it to \(ut:T\to Y\text{.}\) This terminology allows element arguments in a category without choosing an underlying-set functor. To prove \(a,b:X\to Y\) equal, it suffices to prove \(at=bt\) for all generalized elements: take \(T=X\) and \(t=\id_X\text{.}\) The point is useful when an arrow is itself defined through its effect on tests.
