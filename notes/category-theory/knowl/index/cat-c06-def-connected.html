Definition 6.1 Connectedness and the component set.

Two objects of a category \(I\) are in the same component if they can be joined by a finite zigzag
\begin{equation*} i=i_0\longleftrightarrow i_1\longleftrightarrow\cdots\longleftrightarrow i_n=i', \end{equation*}
where each displayed step is an arrow in either direction. A zigzag of length zero is allowed. This is an equivalence relation on \(\Ob(I)\text{;}\) its quotient is denoted \(\pi_0(I)\text{.}\) The category \(I\) is connected if it is nonempty and any two objects are in the same component, equivalently if \(\pi_0(I)\) is a singleton.
