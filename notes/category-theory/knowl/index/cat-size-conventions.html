Definition 0.1 Relative size conventions.

For a set-encoded category \(\mathcal C\text{,}\) we use the following terms.
🔗
  1. It is \(\U\)-small if \(\Ob(\mathcal C)\in\U\) and \(\Ar(\mathcal C)\in\U\text{.}\)
    🔗
    🔗
  2. It is locally \(\U\)-small if \(\Hom_{\mathcal C}(X,Y)\in\U\) for every pair of objects \(X,Y\text{.}\)
    🔗
    🔗
  3. It is essentially \(\U\)-small if it is equivalent to a \(\U\)-small category.
    🔗
    🔗
