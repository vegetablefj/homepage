Definition 14.1 Exponentials and cartesian closure.

For objects \(A,B\text{,}\) an exponential of \(B\) by \(A\) consists of an object \(B^A\) and an evaluation arrow
\begin{equation*} \operatorname{ev}_{A,B}:B^A\times A\longrightarrow B \end{equation*}
such that, for every \(T\text{,}\) the function
\begin{equation*} \Hom_{\mathcal C}(T,B^A)\longrightarrow \Hom_{\mathcal C}(T\times A,B),\qquad k\longmapsto\operatorname{ev}_{A,B}(k\times\id_A) \end{equation*}
is bijective. The inverse sends \(q:T\times A\to B\) to its transpose, or curried arrow, denoted \(\Lambda(q):T\to B^A\text{.}\) A category is cartesian closed if it has finite products, including a terminal object, and an exponential for every pair \(A,B\text{.}\)
