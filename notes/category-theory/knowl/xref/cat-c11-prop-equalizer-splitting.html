Proposition 11.3.

For an idempotent \(e:c\to c\text{,}\) the following conditions are equivalent:
🔗
  1. The idempotent splits.
    🔗
    🔗
  2. The pair \(e,\id_c:c\rightrightarrows c\) has an equalizer.
    🔗
    🔗
  3. The same pair has a coequalizer.
    🔗
    🔗
🔗
In a splitting, \(i:b\to c\) is that equalizer and \(r:c\to b\) that coequalizer. Both universal properties are preserved by every functor. Consequently, having all equalizers, or having all coequalizers, suffices for idempotent completeness.
🔗
🔗

Proof.
Suppose \(ir=e\) and \(ri=\id_b\text{.}\) If \(a:x\to c\) satisfies \(ea=a\text{,}\) then \(i(ra)=ea=a\text{.}\) The factorization is unique because \(i\) is monic. Dually, if \(a:c\to x\) satisfies \(ae=a\text{,}\) then \((ai)r=ae=a\text{,}\) uniquely because \(r\) is epic.
🔗
Conversely, let \(i:b\to c\) equalize \(e\) and \(\id_c\text{.}\) The equality \(e^2=e\) gives a unique \(r:c\to b\) with \(ir=e\text{.}\) Since \(i(ri)=ei=i\) and \(i\) is monic, \(ri=\id_b\text{.}\) If instead \(r:c\to b\) coequalizes the pair, factor \(e\) as \(ir\text{;}\) the equation \((ri)r=re=r\) and epimorphy of \(r\) give the same result. Every functor preserves the splitting equations, so the first paragraph establishes the transported universal properties as well.
