Proposition 3.7.

A pair \((X,u)\) represents a presheaf \(F\) if and only if it is terminal in \(\operatorname{el}(F)\text{.}\) A pair \((X,u)\) represents a covariant functor \(G\) if and only if it is initial in \(\operatorname{el}(G)\text{.}\)
🔗
🔗

Proof.
An arrow \((T,t)\to(X,u)\) in \(\operatorname{el}(F)\) is exactly an arrow \(f:T\to X\) satisfying \(F(f)(u)=t\text{.}\) Terminality is therefore precisely existence and uniqueness in the contravariant universal-element criterion. In the covariant case, an arrow \((X,u)\to(T,t)\) instead satisfies \(G(f)(u)=t\text{,}\) giving initiality.
