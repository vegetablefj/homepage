Definition 13.3 \(\kappa\)-presentable and finitely presentable.

In a category \(\mathcal E\) admitting small \(\kappa\)-filtered colimits, an object \(A\) is \(\kappa\)-presentable if \(\Hom_{\mathcal E}(A,-)\) preserves all these colimits. Thus for each such \(D:I\to\mathcal E\) the canonical map
\begin{equation*} \operatorname{colim}_{i\in I}\Hom(A,D_i)\longrightarrow\Hom(A,\operatorname{colim}_iD_i) \end{equation*}
is bijective. For \(\kappa=\aleph_0\text{,}\) we say finitely presentable. Li calls these objects \(\kappa\)-compact, and calls finitely presentable objects compact; see [LiII, Definition A.2.2 and Remark A.2.3].
