Proposition 9.17.

The map \(q\) in a split coequalizer diagram is a coequalizer of \(f,g\text{,}\) and every functor sends this fork to a coequalizer fork.
🔗
🔗

Proof.
If \(hf=hg\text{,}\) set \(\bar h=hs\text{.}\) Then \(\bar hq=hsq=hft=hgt=h\text{.}\) A factorization is unique because \(q\) has section \(s\text{:}\) necessarily \(\bar h=\bar hqs=hs\text{.}\) Every functor preserves the four displayed equations, so the same proof applies to its image. This is the meaning of absolute here.
