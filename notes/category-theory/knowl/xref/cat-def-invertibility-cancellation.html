Definition 1.4 Invertible and cancellable arrows.

Let \(f:X\to Y\) be an arrow of \(\mathcal C\text{.}\)
🔗
  1. It is an isomorphism if an arrow \(g:Y\to X\) satisfies \(gf=\id_X\) and \(fg=\id_Y\text{.}\) We then write \(f^{-1}=g\) and \(X\cong Y\text{.}\) An automorphism is an isomorphism from an object to itself; the automorphisms of \(X\) form the group \(\Aut_{\mathcal C}(X)\text{.}\) A groupoid is a category in which every arrow is invertible.
    🔗
    🔗
  2. The arrow \(f\) is a split monomorphism, or section, if it has a left inverse \(r:Y\to X\text{,}\) so \(rf=\id_X\text{.}\) It is a split epimorphism, or retraction, if it has a right inverse \(s:Y\to X\text{,}\) so \(fs=\id_Y\text{.}\) More generally, a pair \(X\xrightarrow{s}Y\xrightarrow{r}X\) with \(rs=\id_X\) exhibits \(X\) as a retract of \(Y\text{.}\)
    🔗
    🔗
  3. The arrow \(f\) is a monomorphism if \(fa=fb\) implies \(a=b\) for all parallel arrows \(a,b:T\to X\) and all objects \(T\text{.}\) It is an epimorphism if \(af=bf\) implies \(a=b\) for all parallel arrows \(a,b:Y\to T\text{.}\) We also say monic and epic. An arrow with both properties is a bimorphism. A category is balanced if every bimorphism is an isomorphism.
    🔗
