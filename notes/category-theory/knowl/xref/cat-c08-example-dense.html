Example 8.12 Tests that detect and tests that reconstruct.

  1. The functor \(1\to\Set_\U\) selecting a singleton is dense: its nerve is naturally the identity functor on sets, since \(\Hom(1,S)\cong S\text{.}\) Its canonical presentation writes a set as the coproduct of its singleton elements.
    🔗
    🔗
  2. Let \(\mathsf{Fin}\) be the small category of finite ordinals and all functions between them. Its inclusion in \(\Set_\U\) is dense. A natural transformation between its restricted nerves is determined on the singleton by a function \(v:S\to T\text{.}\) For \(s:n\to S\text{,}\) naturality with every point \(1\to n\) forces its image to be \(vs:n\to T\text{;}\) for \(n=0\) there is only one possible function. Hence it is postcomposition by \(v\text{,}\) proving fullness, and the singleton also proves faithfulness.
    🔗
    🔗
  3. The functor \(1\to\Grp_\U\) selecting the infinite cyclic group has a faithful nerve, since \(\Hom(\Z,G)\) identifies with the underlying set of \(G\text{.}\) It is not dense. Natural transformations between these nerves are arbitrary functions between their single underlying sets, since the source \(1\) imposes no operations. A constant function with nonidentity value in a nontrivial target group is not induced by a homomorphism.
    🔗
    🔗
  4. A dense functor need not be faithful. Let \(\mathcal A\) be the one-object category of a nontrivial small monoid, and send its object to a singleton and every arrow to the identity in \(\Set_\U\text{.}\) Its restricted nerve sends a set to the corresponding trivial right monoid action. Every function between two trivial actions is equivariant, so this nerve is fully faithful. The original functor identifies all monoid arrows.
