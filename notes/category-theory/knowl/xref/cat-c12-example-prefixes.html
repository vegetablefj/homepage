Example 12.12 A set map invisible to finite stages.

Use the finite-set skeleton \(\mathsf{Fin}\) and its inclusion into \(\Set_{\U}\text{.}\) Realization gives \(R:\operatorname{Pro}(\mathsf{Fin})\to\Set_{\U}\text{.}\) Consider the inverse system of finite binary words
\begin{equation*} \cdots\longrightarrow\{0,1\}^3\longrightarrow\{0,1\}^2\longrightarrow\{0,1\}\longrightarrow\{*\}, \end{equation*}
with maps deleting the last letter. Identify these finite sets with chosen finite ordinals and transport the transition maps when using the skeleton. Denote the resulting pro object by \(X\text{.}\) Its realized limit is the set \(\{0,1\}^{\N}\) of infinite binary sequences, with its finite-prefix projections.
🔗
The constant pro object \(2=\{0,1\}\) has
\begin{equation*} \Hom_{\operatorname{Pro}(\mathsf{Fin})}(X,2) \cong\operatorname{colim}_{n\in\N}\Hom_{\Set}(\{0,1\}^n,2). \end{equation*}
Every realized map in this hom-set depends only on a finite prefix. However, the function on infinite sequences which is one on the all-zero sequence and zero on every other sequence has no such description. For every prefix length, an all-zero prefix extends both to the all-zero sequence and to a sequence with a later nonzero coordinate. They receive different values. This function is an arrow in \(\Set_{\U}\) which does not come from a pro map.
🔗
Thus realization is not full, and hence not fully faithful. No topology has been put on the sequence set; the distinction already follows from the elementary mapping formula. The pro object remembers that its allowed maps to finite constant objects are determined at a finite stage. Merely taking the underlying inverse-limit set forgets that restriction on maps.
