Proposition 6.14.

A small category \(I\) is filtered if and only if \(\operatorname{colim}_I:\Fun(I,\Set_\U)\to\Set_\U\) preserves finite limits.
🔗
🔗

Proof.
Only the converse remains. Preservation of the terminal object gives \(\operatorname{colim}_I\Delta1\cong1\text{,}\) so \(I\) is nonempty. For \(i,j\in I\text{,}\) consider \(A=\Hom_I(i,-)\) and \(B=\Hom_I(j,-)\text{.}\) Each has singleton colimit, as in Proposition 6.6. Product preservation implies that \(\operatorname{colim}_I(A\times B)\) is a singleton and in particular nonempty. Some value \(A(k)\times B(k)\) is therefore nonempty. Its element supplies arrows from both \(i\) and \(j\) to \(k\text{.}\)
🔗
For parallel arrows \(a,b:i\to j\text{,}\) precomposition gives transformations \(\Hom_I(j,-)\rightrightarrows\Hom_I(i,-)\text{.}\) Their equalizer has value
\begin{equation*} E(k)=\{c:j\to k:ca=cb\}. \end{equation*}
Both original colimits are singletons, so equalizer preservation makes \(\operatorname{colim}_I E\) a singleton. Consequently some \(E(k)\) is nonempty, giving the required equalization. These are all three filteredness clauses.
