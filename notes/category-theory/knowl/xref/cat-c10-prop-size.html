Proposition 10.5.

The formal localization of a set-encoded category is set-encoded. If \(\mathcal C\) is \(\U\)-small, its path localization is \(\U\)-small. If \(\mathcal C\) is only locally \(\U\)-small, its localization need not be locally \(\U\)-small.
🔗
🔗

Proof.
The edge collection is a set, and the finite paths form a subset of a union, indexed by \(\N\text{,}\) of finite powers of the edge collection, together with the empty paths labeled by objects. Taking a quotient and recording endpoints still gives a set. If all the original category data lie in \(\U\text{,}\) then \(W\text{,}\) the edges, and the finite-word set lie in \(\U\text{,}\) using \(\N\in\U\text{.}\) Subsets, quotient sets, and the endpoint data also lie in \(\U\text{.}\) The counterexample below proves the last assertion.
