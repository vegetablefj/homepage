    Chapter 1 Categories, functors, and natural transformations

    A category specifies which objects are being considered, which arrows connect them, and how arrows compose. A functor transports this entire arrangement. A natural transformation compares two such transports in a way compatible with every arrow. The point of establishing these notions together is that constructions must usually be checked on arrows, and comparisons must usually be checked for naturality.
    We use the size conventions of Definition 0.1. In particular, our categories are encoded by sets, although their sets of objects need not be small relative to the fixed universe \(\U\text{.}\) Unless specified otherwise, their local morphism sets belong to \(\U\text{.}\) The main sources for the language developed here are [LiI, Sections 2.1–2.3], [KS06, Chapter 1], and [Rie, Sections 1.1–1.5]. Our examples use sets, orders, and elementary algebra.

    Section 1.1 Objects, arrows, and composition

    Composition has a direction and a domain of definition. We write \(gf=g\circ f\) for the composite that first applies \(f\) and then \(g\text{.}\) The source and target are part of an arrow’s meaning, even when two arrows happen to have the same underlying formula.

    Definition 1.1 Category and basic notation.

    A category \(\mathcal C\) consists of the following data.
    1. A set \(\Ob(\mathcal C)\) of objects and, for each ordered pair of objects \(X,Y\text{,}\) a set \(\Hom_{\mathcal C}(X,Y)\) of morphisms or arrows from \(X\) to \(Y\text{.}\)
    2. For every object \(X\text{,}\) an identity arrow \(\id_X\in\Hom_{\mathcal C}(X,X)\text{,}\) and for every three objects a composition map
      \begin{equation*} \Hom_{\mathcal C}(Y,Z)\times\Hom_{\mathcal C}(X,Y)\longrightarrow\Hom_{\mathcal C}(X,Z),\qquad (g,f)\longmapsto gf. \end{equation*}
      These maps satisfy \(\id_Yf=f=f\id_X\) and \(h(gf)=(hg)f\) whenever the arrows have the indicated consecutive endpoints.
    We write \(X\in\mathcal C\) for \(X\in\Ob(\mathcal C)\text{.}\) The set of all typed arrows is
    \begin{equation*} \Ar(\mathcal C)=\coprod_{(X,Y)\in\Ob(\mathcal C)^2}\Hom_{\mathcal C}(X,Y). \end{equation*}
    The endomorphism set is \(\End_{\mathcal C}(X)=\Hom_{\mathcal C}(X,X)\text{;}\) its composition and identity make it a monoid.
    The local sets in this definition need not be pairwise disjoint: taking their tagged disjoint union gives each arrow an unambiguous source and target. This distinction also keeps the local size condition separate from the size of object labels.1 In particular, composition is not an operation on every pair of arrows; only matching endpoints allow a composite.
    The object set may be empty. Then every required datum is empty and all axioms hold vacuously; this is the empty category, denoted \(\mathbf 0\text{.}\) If \(X\) is an object, however, its endomorphism set is nonempty because it contains \(\id_X\text{.}\) There is no requirement that \(\Hom_{\mathcal C}(X,Y)\) be nonempty when \(X\ne Y\text{.}\) The identity at \(X\) is forced by the axioms: two candidates \(e,e'\) would satisfy \(e=ee'=e'\text{.}\)

    Example 1.2 Sets, discrete categories, and orders.

    Several basic examples expose different parts of the definition.
    1. In \(\Set=\Set_{\U}\text{,}\) objects are the sets belonging to \(\U\text{,}\) arrows are functions, and composition is ordinary function composition. This is locally \(\U\)-small, but is not \(\U\)-small: its object set is \(\U\) itself. The full subcategory of finite sets is denoted \(\operatorname{FinSet}\text{.}\) Its objects are finite, but that does not make the category a finite category.
    2. A set \(S\) defines a discrete category: the only arrows are the identities. Thus \(\Hom(x,y)\) is empty for distinct objects and is a singleton for equal objects. The terminal category \(\mathbf 1\) is the discrete category on one object. A finite category means one with finitely many objects and finitely many typed arrows. For example, \([n]\) has objects \(0,\ldots,n\) and one arrow \(i\to j\) exactly when \(i\le j\text{.}\)
    3. A preorder \((P,\le)\) defines a category with one arrow \(x\to y\) when \(x\le y\) and none otherwise. Reflexivity gives identities and transitivity gives composition. Conversely, a category with at most one arrow between each pair of objects, called a thin category, determines a preorder. Antisymmetry is an additional condition: if \(x\le y\) and \(y\le x\) force \(x=y\text{,}\) the preorder is a partially ordered set.
    A preorder can therefore contain distinct objects joined by arrows in both directions. Since every available endomorphism is the identity, those arrows are inverse. Passing from a preorder to the quotient by \(x\sim y\) if \(x\le y\le x\) gives a poset; later we will recognize this as replacing a category by equivalent representatives.

    Example 1.3 Algebra and freely generated arrows.

    A monoid \(M\) defines a category with one object \(*\) and \(\Hom(*,*)=M\text{,}\) with \(gf\) interpreted as multiplication in that order. Every one-object category arises this way. This example concerns one monoid encoded as a category. It differs from \(\Mon\text{,}\) the category whose objects are monoids and whose arrows are monoid homomorphisms. Similarly, \(\Grp\) has groups as objects and group homomorphisms as arrows; \(\Ring\) here has associative unital rings and homomorphisms preserving the unit, with commutativity imposed only in its full subcategory \(\CRing\text{.}\)
    A quiver is a set of vertices and a set of directed edges with specified endpoints. It does not yet specify identities or composites. Its free category has the vertices as objects and finite composable paths as arrows, including a length-zero identity path at each vertex; composition concatenates paths. For a quiver with one vertex and one loop, the free category has infinitely many arrows. Thus a finite generating picture need not give a finite category. Assigning the vertices and edges to objects and arrows of any category determines a unique functor from the free category, because the image of a path must be the composite of its edge images.
    A commutative diagram is a collection of objects and arrows for which specified parallel paths have equal composites. Its picture can suppress identities and composite arrows, but these remain part of the category. Conversely, additional relations between paths produce different categories from the same generating quiver. Reading a diagram therefore requires knowing both its arrows and which path equalities are being asserted.

    Section 1.2 Isomorphisms, retracts, and cancellation

    Invertibility is internal to a category: an inverse must itself be an allowed arrow. One-sided inverses and cancellation properties describe weaker conditions. We collect the terminology before recording the relations between it.

    Definition 1.4 Invertible and cancellable arrows.

    Let \(f:X\to Y\) be an arrow of \(\mathcal C\text{.}\)
    1. It is an isomorphism if an arrow \(g:Y\to X\) satisfies \(gf=\id_X\) and \(fg=\id_Y\text{.}\) We then write \(f^{-1}=g\) and \(X\cong Y\text{.}\) An automorphism is an isomorphism from an object to itself; the automorphisms of \(X\) form the group \(\Aut_{\mathcal C}(X)\text{.}\) A groupoid is a category in which every arrow is invertible.
    2. The arrow \(f\) is a split monomorphism, or section, if it has a left inverse \(r:Y\to X\text{,}\) so \(rf=\id_X\text{.}\) It is a split epimorphism, or retraction, if it has a right inverse \(s:Y\to X\text{,}\) so \(fs=\id_Y\text{.}\) More generally, a pair \(X\xrightarrow{s}Y\xrightarrow{r}X\) with \(rs=\id_X\) exhibits \(X\) as a retract of \(Y\text{.}\)
    3. The arrow \(f\) is a monomorphism if \(fa=fb\) implies \(a=b\) for all parallel arrows \(a,b:T\to X\) and all objects \(T\text{.}\) It is an epimorphism if \(af=bf\) implies \(a=b\) for all parallel arrows \(a,b:Y\to T\text{.}\) We also say monic and epic. An arrow with both properties is a bimorphism. A category is balanced if every bimorphism is an isomorphism.
    A left inverse and a right inverse of the same arrow coincide when both exist: if \(rf=\id_X\) and \(fs=\id_Y\text{,}\) then \(r=r(fs)=(rf)s=s\text{.}\) Hence an isomorphism has exactly one inverse. One-sided inverses need not be unique. In the monoid example, invertible arrows are precisely the units of the monoid, so its one-object category is a groupoid exactly when the monoid is a group.

    Proposition 1.5.

    The following properties hold in any category.
    1. Composites of isomorphisms are isomorphisms, with \((gf)^{-1}=f^{-1}g^{-1}\text{.}\) A split monomorphism is monic and a split epimorphism is epic.
    2. Composites of monomorphisms are monic; if \(gf\) is monic, then \(f\) is monic. Dually, composites of epimorphisms are epic; if \(gf\) is epic, then \(g\) is epic.
    3. An arrow which is monic and split epic is an isomorphism. An arrow which is epic and split monic is also an isomorphism.

    Proof.
    The inverse formula follows by composing in both orders. If \(rf=\id_X\text{,}\) multiplying \(fa=fb\) on the left by \(r\) gives \(a=b\text{.}\) For monic \(f,g\text{,}\) an equality \(gfa=gfb\) first cancels \(g\) and then \(f\text{.}\) If only \(gf\) is known to be monic, \(fa=fb\) still implies \(gfa=gfb\text{,}\) hence \(a=b\text{.}\) Finally, if \(fs=\id_Y\) and \(f\) is monic, then \(f(sf)=f=f\id_X\) gives \(sf=\id_X\text{.}\) Reversing all arrows proves the dual assertions.
    The cancellation definitions are equivalent to injectivity of the functions
    \begin{equation*} \Hom_{\mathcal C}(T,X)\longrightarrow\Hom_{\mathcal C}(T,Y),\quad a\longmapsto fa, \end{equation*}
    for monicity, and of \(\Hom_{\mathcal C}(Y,T)\to\Hom_{\mathcal C}(X,T)\text{,}\) \(a\mapsto af\text{,}\) for epicity. The quantifier ranges over all test objects. In a thin category every arrow is both monic and epic, although an arrow in a poset is invertible only when its endpoints are equal.

    Example 1.6 Cancellation and underlying functions.

    In \(\Set\text{,}\) monomorphisms are precisely injective functions: singleton test objects detect equality of individual elements. Epimorphisms are precisely surjective functions. To verify the latter converse, if \(y\in Y\) is outside the image of \(f:X\to Y\text{,}\) the zero function \(Y\to\{0,1\}\) and the function taking value one only at \(y\) agree after composition with \(f\text{,}\) but differ.
    These identifications must be checked in each category. The inclusion \(\Z\to\Q\) in \(\Ring\) is monic and epic, but is not an isomorphism. Monicity follows from injectivity. If two ring maps \(a,b:\Q\to R\) agree on \(\Z\text{,}\) then for every nonzero integer \(n\) they agree on \(n^{-1}\text{,}\) since its image must be the inverse of their common image of \(n\text{.}\) They consequently agree on every rational number. The inclusion is not surjective, and a ring inverse would in particular be an inverse function. This example is also given in [Rie, Exercise 1.2.iv].
    Consequently \(\Set\) is balanced, whereas \(\Ring\) and \(\CRing\) are not. In these ring categories, cancellation does not force bijectivity of the underlying function.
    For a category equipped with a faithful underlying-set functor, injective and surjective underlying functions always give monic and epic arrows, respectively: cancel the functions and use faithfulness. The converse requires more information. Thus the word epimorphism never means surjective by our general convention.2

    Section 1.3 Opposites and subcategories

    Many statements come in pairs obtained by reversing arrows. This operation changes the category under discussion; it is not an instruction to reverse a function while keeping its source and target fixed.

    Definition 1.7 Opposite and subcategories.

    1. The opposite category \(\mathcal C^{\mathrm{op}}\) has the same objects as \(\mathcal C\) and
      \begin{equation*} \Hom_{\mathcal C^{\mathrm{op}}}(X,Y)=\Hom_{\mathcal C}(Y,X). \end{equation*}
      An arrow \(f:X\to Y\) is written \(f^{\mathrm{op}}:Y\to X\) in the opposite. Composition is specified by \(f^{\mathrm{op}}g^{\mathrm{op}}=(gf)^{\mathrm{op}}\text{,}\) and the identity at \(X\) is \((\id_X)^{\mathrm{op}}\text{.}\)
    2. A subcategory \(\mathcal A\subseteq\mathcal C\) consists of a subset of objects and subsets \(\Hom_{\mathcal A}(X,Y)\subseteq\Hom_{\mathcal C}(X,Y)\) containing the required identities and closed under composition. Its structure is inherited from \(\mathcal C\text{.}\) It is full if these morphism subsets are equal to the corresponding morphism sets of \(\mathcal C\text{;}\) it is wide if it has every object of \(\mathcal C\text{.}\)
    3. A category is skeletal if isomorphic objects are equal. A skeleton of \(\mathcal C\) is a full subcategory containing exactly one object from each isomorphism class of objects of \(\mathcal C\text{.}\)
    Associativity and the identity rules for the opposite follow from those of \(\mathcal C\text{,}\) and reversing twice recovers the original structure. An arrow is invertible if and only if its opposite is invertible. Monomorphisms and epimorphisms exchange roles. A categorical statement, including its hypotheses, may therefore be dualized. This principle does not identify a particular category with its opposite.
    The discrete category on \(\Ob(\mathcal C)\) is a wide subcategory of \(\mathcal C\text{,}\) but need not be full. All objects together with all invertible arrows form another wide subcategory, the maximal subgroupoid, often called the core. A full subcategory is determined by its chosen objects. A skeleton of finite sets can be obtained by taking one standard set of each finite cardinality, such as \(\{0,\ldots,n-1\}\text{.}\) It still has all functions between those representatives, not just identity maps.
    A skeleton exists for every set-encoded category under our choice assumption: isomorphism is an equivalence relation on its object set, and one chooses a representative from each class. It is not a canonical collection of objects. A skeleton of a \(\U\)-small category is again \(\U\)-small, but a skeleton of an essentially \(\U\)-small category need not be strictly \(\U\)-small with its inherited object names; an equivalent presentation using small labels may be needed. We will prove below that a skeleton inclusion is an equivalence. Fullness alone does not ensure closure under isomorphism in the ambient category.3

    Section 1.4 Functors and what they detect

    An object assignment becomes a functor only after specifying arrow maps and checking both structure rules. A map of the underlying quivers need not preserve the identity arrows or the composites that the categories already possess.

    Definition 1.8 Functor and comparison properties.

    For categories \(\mathcal C,\mathcal D\text{,}\) a functor \(F:\mathcal C\to\mathcal D\) assigns an object \(FX\) to each \(X\) and a function
    \begin{equation*} F_{X,Y}:\Hom_{\mathcal C}(X,Y)\longrightarrow\Hom_{\mathcal D}(FX,FY) \end{equation*}
    to each pair, such that \(F(\id_X)=\id_{FX}\) and \(F(gf)=F(g)F(f)\text{.}\) When its direction is clear, this is also called a covariant functor.
    1. It is faithful if every \(F_{X,Y}\) is injective, full if every \(F_{X,Y}\) is surjective, and fully faithful if all these functions are bijective.
    2. It is essentially surjective if each object of \(\mathcal D\) is isomorphic to some \(FX\text{.}\) It is conservative if \(F(f)\) being invertible always implies that \(f\) is invertible.
    3. Its essential image is the full subcategory of \(\mathcal D\) on all objects isomorphic to some \(FX\text{.}\) In particular it is replete: it contains every ambient object isomorphic to one of its objects. Its arrows are all ambient arrows between the chosen objects, not only arrows in the image of \(F\text{.}\)
    4. A contravariant functor from \(\mathcal C\) to \(\mathcal D\) means a functor \(\mathcal C^{\mathrm{op}}\to\mathcal D\text{.}\) Thus it assigns to \(f:X\to Y\) an arrow \(F(f):FY\to FX\text{,}\) with \(F(gf)=F(f)F(g)\text{.}\)
    Identity functors and composites of functors are defined on both objects and arrows; their structure rules follow immediately. A covariant functor \(F:\mathcal C\to\mathcal D\) also induces a covariant functor
    \begin{equation*} F^{\mathrm{op}}:\mathcal C^{\mathrm{op}}\to\mathcal D^{\mathrm{op}},\qquad f^{\mathrm{op}}\longmapsto F(f)^{\mathrm{op}}. \end{equation*}
    This construction reverses both categories. It differs from declaring \(F\) contravariant, which reverses only the source in the notation for the functor’s domain.

    Example 1.9 Order maps and algebraic forgetful functors.

    A functor between preorder categories is exactly an order-preserving map of their object sets. The inclusion of a subcategory is faithful, and is full exactly when the subcategory is full. The forgetful functor \(\Grp\to\Set\) is faithful and conservative: group homomorphisms are determined by their functions, and the inverse function of a bijective homomorphism is again a homomorphism. It is not full, since arbitrary functions between groups need not respect multiplication.
    For a fixed object \(A\text{,}\) postcomposition defines a covariant functor \(\Hom_{\mathcal C}(A,-):\mathcal C\to\Set\text{,}\) whereas precomposition defines a functor \(\Hom_{\mathcal C}(-,A):\mathcal C^{\mathrm{op}}\to\Set\text{.}\) Their identity and composition rules are precisely the identity and associativity rules of the category. A functor between one-object monoid categories is a homomorphism of monoids, including preservation of the unit.

    Proposition 1.10.

    1. Every functor preserves isomorphisms and their inverses. Every fully faithful functor is conservative.
    2. If \(F\) is fully faithful, then \(FX\cong FY\) if and only if \(X\cong Y\text{.}\) The forward implication concerns existence of an isomorphism between the image objects, not merely the image of a previously specified arrow.
    3. Composites of faithful, full, fully faithful, essentially surjective, or conservative functors have the respective property.

    Proof.
    Apply a functor to the two inverse equations to obtain the first preservation assertion. If \(F(f)\) is invertible and \(F\) is fully faithful, fullness lifts its inverse to an arrow \(g\text{;}\) faithfulness converts \(F(gf)=\id_{FX}\) and \(F(fg)=\id_{FY}\) into the inverse equations for \(f\text{.}\) More generally, fullness first lifts an isomorphism \(FX\to FY\) itself, and the same argument applies. The morphism-set properties are closed under composition of functions. Essential surjectivity of a composite uses preservation of the isomorphism witnessing the first choice of a preimage; conservativity applies successively.
    Faithfulness refers to each fixed pair of objects. It does not require the object map to be injective. For example, the category with two objects and exactly one arrow between every pair maps fully faithfully to \(\mathbf 1\text{.}\) Conversely, a faithful functor need not be conservative: the functor from the poset \(0<1\) to \(\mathbf 1\) sends its noninvertible arrow to an identity. Essential surjectivity likewise need not provide equality with an image object; it provides an isomorphism.
    Every functor factors through its essential image, and its corestriction to that full subcategory is essentially surjective. This construction is preferable to treating the raw arrow image as a subcategory: the latter need not be closed under composition. For example, map the two components of \([1]\amalg[1]\) to the consecutive arrows \(0\to1\) and \(1\to2\) in \([2]\text{.}\) Their images compose, although the two source arrows do not. The composite \(0\to2\) is absent from the raw image. The full essential image does contain it. Later, the equivalence criterion will identify a fully faithful functor with an equivalence onto its essential image.
    Preservation of isomorphisms follows from explicit inverse equations, which a functor carries to inverse equations. Preservation of monomorphisms or epimorphisms does not follow from the functor axioms alone. For example, the unique nonidentity arrow of the poset category \(0<1\) is both monic and epic. A functor to \(\Set\) can send it to any function between the two chosen image sets, including a noninjective or nonsurjective function. The source cancellation tests involve only source arrows, whereas the target tests involve every target arrow. This explains why preservation statements later in the notes require additional hypotheses.

    Section 1.5 Natural transformations

    Let \(F,G:\mathcal C\to\mathcal D\) be functors. Choosing one arrow \(FX\to GX\) for each object is only the first step of comparing them. These components must satisfy a commuting square for every arrow in the source category.

    Definition 1.11 Natural transformation and natural isomorphism.

    A natural transformation \(\eta:F\Rightarrow G\) is a family \((\eta_X)_{X\in\Ob(\mathcal C)}\) with \(\eta_X:FX\to GX\text{,}\) such that for each arrow \(f:X\to Y\text{,}\)
    \begin{equation*} G(f)\eta_X=\eta_YF(f). \end{equation*}
    The arrow \(\eta_X\) is its component at \(X\text{.}\) We write \(\Nat(F,G)\) for the set of such transformations. A natural isomorphism is a natural transformation whose every component is an isomorphism; it is denoted \(F\cong G\text{.}\)
    The naturality square compares two routes from \(FX\) to \(GY\text{:}\) first compare and then apply \(G(f)\text{,}\) or first apply \(F(f)\) and then compare. The family must work for all source arrows, including automorphisms and maps between distinct objects. A comparison chosen independently for each object frequently fails this test. For contravariant functors the definition is applied to \(\mathcal C^{\mathrm{op}}\text{;}\) for \(f:X\to Y\) in \(\mathcal C\text{,}\) the equation becomes \(G(f)\eta_Y=\eta_XF(f)\text{.}\)

    Example 1.14 Singletons and a failure of arbitrary choices.

    On \(\Set\text{,}\) let \(\mathcal P(X)\) be the power set and send \(f:X\to Y\) to direct image \(A\mapsto f(A)\text{.}\) The functions \(\sigma_X:X\to\mathcal P(X)\text{,}\) \(x\mapsto\{x\}\text{,}\) form a natural transformation from the identity functor to \(\mathcal P\text{,}\) because \(f(\{x\})=\{f(x)\}\text{.}\) Here the same rule interacts correctly with every function.
    In contrast, a natural transformation from the constant singleton functor to the identity on the category of nonempty sets would select elements \(x_X\in X\) satisfying \(f(x_X)=x_Y\) for every function \(f:X\to Y\text{.}\) A two-element set has a permutation with no fixed point, so this is impossible, despite the existence of an element in each object. Ordinary existence and compatibility under maps are different demands.
    For a one-object category coming from a monoid \(M\text{,}\) two functors to another one-object monoid category give homomorphisms \(F,G:M\to N\text{.}\) A natural transformation between them is an element \(a\in N\) satisfying \(G(m)a=aF(m)\) for every \(m\in M\text{.}\) Thus even one component can carry a substantial compatibility condition.
    If the source category is discrete, there are no naturality restrictions beyond the identity equations, which are automatic. If it is empty, there is exactly one functor to any category and exactly one transformation between such functors: the empty family. These cases are useful checks on later constructions rather than exceptions to the definition.

    Section 1.6 Composition and changing the source or target

    Natural transformations can be composed between functors with a common source and target, or transported by composing those functors with another functor. These operations will let us manipulate comparisons without making new component choices.

    Definition 1.15 Vertical composition, whiskering, and horizontal composition.

    1. For \(\eta:F\Rightarrow G\) and \(\theta:G\Rightarrow K\text{,}\) their vertical composite is \(\theta\cdot\eta:F\Rightarrow K\) with components \((\theta\cdot\eta)_X=\theta_X\eta_X\text{.}\) The identity transformation \(\id_F:F\Rightarrow F\) has components \(\id_{FX}\text{.}\)
    2. For \(L:\mathcal B\to\mathcal C\) and \(H:\mathcal D\to\mathcal E\text{,}\) the whiskered transformations \(\eta L:FL\Rightarrow GL\) and \(H\eta:HF\Rightarrow HG\) have components \(\eta_{LB}\) and \(H(\eta_X)\text{,}\) respectively.
    3. For \(\eta:F\Rightarrow G\) with \(F,G:\mathcal C\to\mathcal D\) and \(\theta:H\Rightarrow K\) with \(H,K:\mathcal D\to\mathcal E\text{,}\) their horizontal composite \(\theta*\eta:HF\Rightarrow KG\) has components
      \begin{equation*} (\theta*\eta)_X=\theta_{GX}H(\eta_X)=K(\eta_X)\theta_{FX}. \end{equation*}
      The equality is the naturality of \(\theta\) applied to the arrow \(\eta_X\text{.}\)

    Proposition 1.16.

    The transformations just defined are natural. Vertical and horizontal composition are associative with their indicated identity transformations, and whiskering preserves vertical composition and identities. If \(\eta:F_0\Rightarrow F_1\text{,}\) \(\eta':F_1\Rightarrow F_2\text{,}\) \(\theta:H_0\Rightarrow H_1\text{,}\) and \(\theta':H_1\Rightarrow H_2\) have matching source and target categories, then the interchange identity holds:
    \begin{equation*} (\theta'\cdot\theta)*(\eta'\cdot\eta)=(\theta'*\eta')\cdot(\theta*\eta). \end{equation*}
    Both sides are transformations \(H_0F_0\Rightarrow H_2F_2\text{.}\)
    The horizontal units are the identity transformations of the identity functors. Explicitly, for \(\eta:F\Rightarrow G\) with \(F,G:\mathcal C\to\mathcal D\text{,}\)
    \begin{equation*} \id_{\id_{\mathcal D}}*\eta=\eta=\eta*\id_{\id_{\mathcal C}}. \end{equation*}
    This differs from vertical composition, whose unit at a fixed functor \(F\) is \(\id_F\text{.}\)

    Proof.
    For vertical composition, naturality first gives \(K(f)\theta_X\eta_X=\theta_YG(f)\eta_X\) and then \(\theta_YG(f)\eta_X=\theta_Y\eta_YF(f)\text{.}\) Precomposition substitutes \(L(f)\) in a naturality equation, while postcomposition applies \(H\) to that equation. The horizontal composite is consequently a composite of whiskered natural transformations.
    For interchange, expanding the right side at \(X\) gives
    \begin{equation*} \theta'_{F_2X}H_1(\eta'_X)\theta_{F_1X}H_0(\eta_X) =\theta'_{F_2X}\theta_{F_2X}H_0(\eta'_X)H_0(\eta_X). \end{equation*}
    The equality uses naturality of \(\theta\) at \(\eta'_X\text{;}\) the final expression is the left side. Vertical associativity and identities are those of the component arrows. Horizontal associativity follows by expanding three transformations with the same component formula and using functoriality; both parenthesizations give the composite of the three appropriately whiskered components. Identity transformations give the asserted units by the same formula.
    The displayed types are part of these rules. Vertical composition requires a shared middle functor, whereas horizontal composition requires consecutive source and target categories. For example, \(H\eta=\id_H*\eta\) and \(\eta L=\eta*\id_L\text{.}\) These operations only organize functors and transformations between ordinary categories; no additional theory is needed to use them.4

    Section 1.7 Functor categories and natural isomorphisms

    Vertical composition allows comparisons themselves to serve as arrows of a category. Keeping this category visible is useful: an assertion about functors being isomorphic is then an ordinary assertion about objects and arrows.

    Definition 1.17 Functor category.

    The functor category \(\Fun(\mathcal C,\mathcal D)\) has functors \(\mathcal C\to\mathcal D\) as its objects, morphism sets \(\Nat(F,G)\text{,}\) and vertical composition as its composition law. Its identity at \(F\) is \(\id_F\text{.}\)
    The preceding proposition verifies its category axioms. Its objects and arrows are sets under our set-encoding convention: object maps, local arrow maps, and component families are subsets of sets of possible functions. If \(\mathcal C\) is \(\U\)-small and \(\mathcal D\) is locally \(\U\)-small, then
    \begin{equation*} \Nat(F,G)\subseteq\prod_{X\in\Ob(\mathcal C)}\Hom_{\mathcal D}(FX,GX) \end{equation*}
    belongs to \(\U\text{.}\) Thus the functor category is locally \(\U\)-small. If both categories are \(\U\)-small, their functor category is \(\U\)-small as well. For a source that is not \(\U\)-small, these conclusions at the same scale do not follow: one must check the size or work in a larger universe.5

    Proposition 1.18.

    A transformation \(\eta:F\Rightarrow G\) is an isomorphism in \(\Fun(\mathcal C,\mathcal D)\) if and only if every component \(\eta_X\) is invertible. Its inverse then has components \(\eta_X^{-1}\text{.}\)

    Proof.
    An inverse transformation gives inverse component arrows by the definition of vertical composition. Conversely, if every component is invertible, the naturality equation implies
    \begin{equation*} F(f)\eta_X^{-1}=\eta_Y^{-1}G(f) \end{equation*}
    after multiplication by the inverse components on the two sides. Thus the inverse family is natural, and its vertical composites with \(\eta\) have identity components.
    The condition concerns the components of a specified natural transformation. The weaker assertion that \(FX\) and \(GX\) happen to be isomorphic for every \(X\) need not yield a natural isomorphism. For example, take the source to be the one-object group category of a nontrivial finite group \(M\text{,}\) and the target its one-object group category as well. The identity homomorphism and the trivial homomorphism have the same image object, but a natural isomorphism would be an invertible \(a\in M\) with \(a=am\) for every \(m\in M\text{,}\) which is impossible. Naturality therefore retains information invisible at the level of image objects.

    Section 1.8 Equivalence and the choice of representatives

    An isomorphism of categories requires inverse functors with literal equality of the two composites to the identity functors. Many comparisons in mathematics instead recover objects by isomorphisms compatible with arrows. Equivalence records this latter situation.

    Definition 1.19 Equivalence of categories.

    A functor \(F:\mathcal C\to\mathcal D\) is an equivalence if there is a functor \(G:\mathcal D\to\mathcal C\) and natural isomorphisms
    \begin{equation*} \eta:\id_{\mathcal C}\Rightarrow GF,\qquad \varepsilon:FG\Rightarrow\id_{\mathcal D}. \end{equation*}
    Such a functor \(G\) is called a quasi-inverse. We write \(\mathcal C\simeq\mathcal D\) when an equivalence exists.
    The definition does not impose extra equations on the two specified natural isomorphisms. In particular, they need not initially satisfy the compatibility equations used for an adjunction. The next criterion constructs the comparison maps explicitly, and explains where choice enters.

    Proposition 1.20.

    A functor between our set-encoded categories is an equivalence if and only if it is fully faithful and essentially surjective.

    Proof.
    First suppose \(F\) has a quasi-inverse \(G\) with comparisons \(\eta,\varepsilon\text{.}\) Essential surjectivity follows from \(\varepsilon_Y:FGY\cong Y\text{.}\) If \(Ff=Fg\text{,}\) apply \(G\) and conjugate by the components of \(\eta\) to obtain \(f=g\text{;}\) hence \(F\) is faithful. The same argument with \(\varepsilon\) shows that \(G\) is faithful. Given \(h:FX\to FX'\text{,}\) set \(f=\eta_{X'}^{-1}G(h)\eta_X\text{.}\) Naturality of \(\eta\) at this arrow gives \(GF(f)=G(h)\text{.}\) Since \(G\) is faithful, \(F(f)=h\text{.}\) Thus \(F\) is full. This argument uses naturality rather than assuming unmentioned compatibility between the two comparisons.
    Conversely, suppose \(F\) is fully faithful and essentially surjective. For every \(Y\in\mathcal D\text{,}\) choose an object \(GY\in\mathcal C\) and an isomorphism \(\varepsilon_Y:F(GY)\to Y\text{.}\) These choices are indexed by the set \(\Ob(\mathcal D)\text{,}\) and the possible pairs form sets, so the axiom of choice supplies them. No choice indexed by a proper class is being made.
    For an arrow \(b:Y\to Y'\text{,}\) define \(G(b):GY\to GY'\) to be the unique lift under full faithfulness of
    \begin{equation*} \varepsilon_{Y'}^{-1}b\varepsilon_Y:F(GY)\longrightarrow F(GY'). \end{equation*}
    The image of \(G(\id_Y)\) is an identity, so faithfulness gives \(G(\id_Y)=\id_{GY}\text{.}\) The image of \(G(cb)\) equals the product of the images of \(G(c)\) and \(G(b)\text{,}\) by cancellation of the middle \(\varepsilon\) factors; faithfulness gives \(G(cb)=G(c)G(b)\text{.}\) Hence \(G\) is a functor. Its defining equation makes \(\varepsilon:FG\Rightarrow\id_{\mathcal D}\) natural.
    For each \(X\text{,}\) let \(\eta_X:X\to GFX\) be the unique lift of \(\varepsilon_{FX}^{-1}\text{.}\) It is invertible by Proposition 1.10. For \(f:X\to X'\text{,}\) the definition of \(G(Ff)\) yields
    \begin{equation*} F\bigl(G(Ff)\eta_X\bigr) =\varepsilon_{FX'}^{-1}F(f) =F\bigl(\eta_{X'}f\bigr). \end{equation*}
    Faithfulness makes \(\eta\) natural. Both comparisons have invertible components, so they are natural isomorphisms by Proposition 1.18. This proves the equivalence.
    The criterion and its representative construction are treated in [LiI, Section 2.2, Theorem 2.2.13] and [Rie, Section 1.5]. The quasi-inverse depends on choices, but any two quasi-inverses of a fixed equivalence are naturally isomorphic. More precisely, if \(G,G'\) have comparisons \(\varepsilon:FG\Rightarrow\id_{\mathcal D}\) and \(\varepsilon':FG'\Rightarrow\id_{\mathcal D}\text{,}\) full faithfulness determines \(\tau_Y:GY\to G'Y\) uniquely by
    \begin{equation*} F(\tau_Y)=(\varepsilon'_Y)^{-1}\varepsilon_Y. \end{equation*}
    Naturality of the two comparisons and faithfulness prove naturality of \(\tau\text{,}\) and its components are invertible. This gives uniqueness with the comparisons fixed; it does not say that there is exactly one natural isomorphism between bare quasi-inverse functors.

    Example 1.21 Equivalent presentations.

    A skeleton inclusion is fully faithful by definition and essentially surjective because every object has a representative. It is therefore an equivalence. For a preorder, the poset of equivalence classes described earlier gives the same phenomenon without having to choose a full subcategory first.
    The groupoid with two distinct objects and exactly one arrow between every pair is equivalent to \(\mathbf 1\text{,}\) but is not isomorphic to it as a category. An isomorphism of categories would induce a bijection on object sets. Every arrow in this groupoid, including the arrows between its two objects, is invertible; its two objects nevertheless have distinct labels.
    For a field \(k\) whose underlying set belongs to \(\U\text{,}\) the category with objects the nonnegative integers and arrows \(n\to m\) the \(m\times n\) matrices over \(k\) is equivalent to the category of finite-dimensional vector spaces whose underlying sets belong to \(\U\text{.}\) The functor sends \(n\) to \(k^n\) and a matrix to its linear map. It is fully faithful by matrix representation and essentially surjective by the existence of a basis. Zero-dimensional spaces and empty matrices include the object \(n=0\text{.}\) No assertion that every vector space literally equals one of these coordinate spaces is required.
    Equivalences compose: quasi-inverses compose in reverse order, and whiskering the comparison isomorphisms gives comparisons for the composite. They are symmetric because a quasi-inverse is itself an equivalence. These observations make equivalence an appropriate way to compare different presentations of the same categorical structure. They do not permit replacing actual equality of arrows by unspecified isomorphisms; a commutative diagram still asserts equal composites in its particular category.
