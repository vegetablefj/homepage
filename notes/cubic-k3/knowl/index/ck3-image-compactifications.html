The compactification theorem makes the boundary comparison precise. The GIT compactification is isomorphic to the Looijenga arrangement compactification associated with \(\mathcal H_\infty\text{,}\) by [Laz10, Theorem 1.2] and [Loo09, Theorem 4.1]. We use the arrangement construction through this compactification theorem. It modifies the Baily–Borel model along the arrangement before contracting in a different direction. On the GIT side the Veronese cubic is one point, whereas its smoothing directions can carry different degree-two K3 periods. The modification is what allows these descriptions to fit the same compactification theorem. For the comparison with cubic moduli, see also [Huy23, Chapter 6, Sections 6.5 and 6.7].
