Definition 8.1.

For \(K\in\D(X;\Lambda)\) and an open set \(U\subseteq X\text{,}\) define
\begin{equation*} H^n(U,K)=H^n(R\Gamma(U,K)). \end{equation*}
For a sheaf \(F\) placed in degree zero, these are its sheaf cohomology groups. For a complex they are also called hypercohomology groups. We use the same notation in both cases. If \(K\to I\) is a K-injective resolution on \(X\text{,}\) then
\begin{equation*} H^n(U,K)=H^n(\Gamma(U,I)). \end{equation*}
