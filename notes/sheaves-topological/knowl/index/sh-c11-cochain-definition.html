Definition 11.1 Singular cochains with local coefficients.

For \(n\geq0\text{,}\) let \(S_n(X)\) be the set of continuous maps \(\sigma:\Delta^n\to X\text{,}\) with ordered vertices \(v_0,\ldots,v_n\text{.}\) Define
\begin{equation*} C^n_{\mathrm{sing}}(X;L)=\prod_{\sigma\in S_n(X)}L_{\sigma(v_0)}. \end{equation*}
For a cochain \(c\) and an \((n+1)\)-simplex \(\sigma\text{,}\) set
\begin{equation*} (dc)(\sigma)=T_{\sigma[01]}^{-1}c(\sigma\partial_0)+\sum_{i=1}^{n+1}(-1)^i c(\sigma\partial_i), \end{equation*}
where \(\partial_i\) omits the \(i\)th vertex and \(\sigma[01]\) is the edge from the first to the second vertex. The cohomology of this complex is denoted \(H^n_{\mathrm{sing}}(X;L)\text{.}\)
