Definition 5.1 Constant sheaf.

For a set \(A\text{,}\) the constant sheaf \(A_X\) is the sheaf associated to the constant presheaf with value \(A\text{.}\) Equivalently,
\begin{equation*} A_X(U)=\{s:U\to A:s\text{ is locally constant}\}, \end{equation*}
where \(A\) has the discrete topology. For a \(\Lambda\)-module \(M\text{,}\) the constant sheaf \(M_X\) has this description with pointwise module operations. A sheaf is constant if it is isomorphic to \(A_X\) or \(M_X\text{,}\) as appropriate.
