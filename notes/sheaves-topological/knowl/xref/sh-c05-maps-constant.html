Proposition 5.5.

Let \(M,N\) be modules.
  1. A morphism \(M_X\to N_X\) is the same as a family of linear maps \(h_x:M\to N\) such that, for every \(m\in M\text{,}\) the function \(x\mapsto h_x(m)\) is locally constant.
    🔗
    🔗
  2. If \(M\) is finitely generated, this family is locally constant as a function to the set \(\Hom_\Lambda(M,N)\) with its discrete topology.
    🔗
    🔗
  3. If \(X\) is connected and nonempty, the family is constant, without a finite-generation hypothesis.
    🔗
    🔗
🔗
🔗

Proof.
The constant-sheaf adjunction identifies a morphism with a map \(M\to\Gamma(X,N_X)\text{,}\) which is precisely the first description. Conversely, evaluating these functions on any locally constant section of \(M_X\) gives the required section of \(N_X\text{.}\) For the second assertion choose finitely many generators of \(M\) and intersect neighbourhoods on which their images have constant values. The map is determined by these images. For the third, each function \(x\mapsto h_x(m)\) is constant by connectedness, for every \(m\text{.}\)
