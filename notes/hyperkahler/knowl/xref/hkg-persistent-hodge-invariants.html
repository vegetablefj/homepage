Proposition 11.15.

A class \(\alpha\in H^{2p}(X,\C)\) remains of type \((p,p)\) on all small deformations if and only if \(D\alpha=0\) for every \(D\in\overline{\mathfrak g}\text{.}\) In particular, the reduced LLV algebra annihilates every Chern class \(c_i(T_X)\text{.}\)
🔗
🔗

Proof.
If the reduced algebra annihilates \(\alpha\text{,}\) the Hodge operator \(f_t\) of every nearby complex structure annihilates its parallel transport, since \(f_t\) belongs to that reduced algebra. On cohomological degree \(2p\text{,}\) the zero eigenspace of \(f_t\) is exactly type \((p,p)\text{.}\)
🔗
Conversely, suppose \(\alpha\) remains of type \((p,p)\text{.}\) Let \(V_{\R}=H^2(X,\R)\text{.}\) By Proposition 4.6 and local Torelli, the periods of small deformations range over an open set of oriented positive two-planes in \(V_{\R}\text{.}\) For an oriented \(q_X\)-orthonormal basis \(u,v\) of such a plane, the period line is \(\C(u+iv)\text{.}\) The Hodge operator on \(V_{\R}\) is
\begin{equation*} f_{u,v}(w)=2\bigl(q_X(u,w)v-q_X(v,w)u\bigr). \end{equation*}
Indeed, it sends \(u+iv\) to \(-2i(u+iv)\text{,}\) its conjugate to \(2i(u-iv)\text{,}\) and annihilates the orthogonal complement, which is the real \((1,1)\) subspace. Since \(\alpha\) has type \((p,p)\text{,}\) every corresponding operator in \(\overline{\mathfrak g}_{\R}\) annihilates it.
🔗
These operators span \(\mathfrak{so}(V_{\R},q_X)\text{.}\) To see this, identify that algebra with \(\bigwedge^2V_{\R}\) by
\begin{equation*} u\wedge v\longmapsto\bigl(w\longmapsto q_X(u,w)v-q_X(v,w)u\bigr). \end{equation*}
If a linear functional on \(\bigwedge^2V_{\R}\) vanished on the wedges from the indicated open set of positive planes, its value on \(u\wedge v\) would vanish for an open set of pairs \((u,v)\in V_{\R}^2\text{:}\) orthonormalizing a positively oriented basis only multiplies its wedge by a nonzero scalar. This value is a bilinear polynomial in \(u,v\text{;}\) vanishing on an open set makes it identically zero. Decomposable wedges span the exterior square, so the functional is zero. Restriction to \(V_{\R}\) identifies the reduced LLV algebra with this orthogonal algebra. Hence the Hodge operators span the reduced algebra itself, which therefore annihilates \(\alpha\text{.}\)
🔗
In a smooth holomorphic deformation, the relative tangent bundle restricts to the tangent bundle of each fibre. Its Chern classes form flat sections of the cohomology local systems and have type \((i,i)\) on each fibre. They satisfy the stated condition.
