Definition 15.3.

For a unipotent operator \(T\text{,}\) set
\begin{equation} N=\log T:=\sum_{j\geq1}\frac{(-1)^{j+1}}j(T-\id)^j.\tag{15.1} \end{equation}
The sum is finite. We use \(N_d=N|_{H^d(X,\Q)}\text{.}\) For a nonzero nilpotent operator \(A\text{,}\) its nilpotency index is
\begin{equation*} \nu(A):=\max\{j\geq0:A^j\ne0\},\qquad \nu(0):=0. \end{equation*}
Thus a largest Jordan block of length \(r+1\) gives \(\nu(A)=r\text{.}\) Write \(\nu_d=\nu(N_d)\text{.}\)
