Definition 8.2 Module sheaves.

An \(\mathcal O\)-module is an Abelian group object \(M\) of \(\mathcal E\) with an action \(\mathcal O\times M\to M\) satisfying the unital and distributive module identities. Its morphisms are action-preserving morphisms of Abelian objects. Write \(\Mod(\mathcal O)\) for this category.
🔗
In a site presentation, \(M(U)\) is an \(\mathcal O(U)\)-module and restriction maps are linear relative to the restriction maps of scalars. For \(A\in\mathcal E\text{,}\) write \(\mathcal O_A\) and \(M|_A\) for their inverse images in \(\mathcal E/A\text{.}\) For a site object \(U\text{,}\) this agrees with restriction to \(\mathcal C/U\text{;}\) the corresponding topos object is \(a h_U\text{,}\) not necessarily \(h_U\) itself.
