Definition 8.5 Free modules on sheaf objects.

For a set sheaf \(A\text{,}\) the free \(\mathcal O\)-module \(\mathcal O[A]\) is characterized by
\begin{equation*} \Hom_{\mathcal O}(\mathcal O[A],M)\simeq\Hom_{\mathcal E}(A,\operatorname{For}M). \end{equation*}
Here \(\operatorname{For}M\) is its underlying set object. The free module can be constructed by sheafifying \(U\mapsto\mathcal O(U)[A(U)]\text{.}\) For a site object \(U\text{,}\) let \(P_U=\mathcal O[a h_U]\text{.}\) Equivalently, \(P_U\) is the sheafification of
\begin{equation*} V\longmapsto\bigoplus_{\alpha:V\to U}\mathcal O(V). \end{equation*}
