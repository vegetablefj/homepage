Definition 11.9.

A complex is strictly perfect if it has finitely many nonzero terms and each term is a direct summand of a finite free module. For \(m\in\Z\text{,}\) an object \(K\in\D(\mathcal O)\) is \(m\)-pseudo-coherent if locally there is a strictly perfect complex \(P\) and a morphism \(P\to K\) inducing an isomorphism on \(\mathcal H^j\) for \(j>m\) and an epimorphism for \(j=m\text{.}\) It is pseudo-coherent if this holds for every \(m\text{.}\) The coverings and approximations may depend on \(m\text{.}\)
🔗
An object has Tor amplitude in \([a,b]\) if \(\mathcal H^i(K\Ltensor_{\mathcal O}M)=0\) for every module \(M\) and every \(i\notin[a,b]\text{.}\) It has locally finite Tor amplitude if locally such an interval exists, with endpoints allowed to vary.
