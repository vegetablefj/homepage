Definition 5.1 Projective and injective objects.

Let \(\mathcal A\) be abelian.
  1. An object \(P\) is projective if every map \(P\to B\) lifts along every epimorphism \(A\to B\text{.}\) Equivalently, the functor \(\Hom_{\mathcal A}(P,-):\mathcal A\to\Ab\) is exact.
    🔗
    🔗
  2. An object \(I\) is injective if every map \(A\to I\) extends along every monomorphism \(A\to B\text{.}\) Equivalently, \(\Hom_{\mathcal A}(-,I):\mathcal A^{\op}\to\Ab\) is exact.
    🔗
    🔗
  3. The category has enough projectives if every object is an epimorphic image of a projective object, and enough injectives if every object embeds in an injective object.
    🔗
    🔗
The equivalences follow because each Hom functor is already left exact in its covariant interpretation; lifting or extension supplies the remaining surjectivity.
