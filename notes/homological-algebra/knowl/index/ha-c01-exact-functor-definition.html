Definition 1.18 Exactness of additive functors.

Let \(F:\mathcal A\to\mathcal B\) be additive between abelian categories. It is left exact if it sends every short exact sequence to an exact sequence \(0\to F(X)\to F(Y)\to F(Z)\text{;}\) it is right exact if \(F(X)\to F(Y)\to F(Z)\to0\) is exact. It is exact if it has both properties.
