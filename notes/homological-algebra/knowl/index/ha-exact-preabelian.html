Definition A.4 Preabelian categories, image, and coimage.

An additive category is preabelian if every morphism has a kernel and a cokernel. For \(f:A\to B\text{,}\) define
\begin{equation*} \operatorname{coim}f=\coker(\ker f\to A),\qquad \im f=\ker(B\to\coker f). \end{equation*}
The morphism factors canonically as \(A\to\operatorname{coim}f\xrightarrow{\overline f}\im f\to B\text{.}\) It is strict if \(\overline f\) is an isomorphism. A strict monomorphism or strict epimorphism is a morphism with both stated properties.
