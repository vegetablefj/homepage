Definition 14.1 Compactness and generation.

Let \(\mathcal T\) have small coproducts.
🔗
  1. An object \(C\) is compact if the canonical map \(\bigoplus_i\Hom(C,X_i)\to\Hom(C,\bigoplus_iX_i)\) is an isomorphism for every small family. Write \(\mathcal T^c\) for the full subcategory of compact objects.
    🔗
    🔗
  2. A set \(G\) detects zero objects if \(\Hom(g,X[n])=0\) for every \(g\in G\) and \(n\in\Z\) implies \(X=0\text{.}\) We call \(\mathcal T\) compactly generated if such a small set can be chosen with every \(g\) compact.
    🔗
    🔗
  3. A localizing subcategory is a strictly full triangulated subcategory closed under small coproducts. Write \(\Loc(G)\) for the smallest one containing \(G\text{.}\) Write \(\thick(G)\) for closure under finite sums, shifts, triangles, and retracts. A classical generator \(g\) satisfies \(\thick(g)=\mathcal T\text{.}\)
    🔗
