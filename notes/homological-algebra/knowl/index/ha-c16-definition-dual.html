Definition 16.4 Dualizable and invertible objects.

An object \(A\) is dualizable if there is an object \(A^\vee\) with evaluation and coevaluation maps
🔗
\begin{equation*} e:A^\vee\otimes A\longrightarrow\mathbf1,\qquad c:\mathbf1\longrightarrow A\otimes A^\vee \end{equation*}
🔗
such that inserting \(c\) and then applying \(e\) gives the identity on \(A\) and on \(A^\vee\text{.}\) Associativity and unit isomorphisms are understood in these two triangle identities. An object is invertible if tensoring with it is an equivalence, or equivalently if it has a tensor inverse.
