Definition 1.12 Chain conditions and length.

An object of an abelian category is noetherian if every increasing sequence of subobjects stabilizes, and artinian if every decreasing sequence stabilizes. A nonzero object is simple if it has no proper nonzero subobject. An object has finite length if it has a finite filtration by subobjects with simple successive quotients; zero has length zero.
