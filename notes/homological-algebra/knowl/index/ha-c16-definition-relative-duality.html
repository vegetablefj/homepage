Definition 16.7 Relative duality.

For \(\omega\in\mathcal T\text{,}\) set \(D_\omega A=[A,\omega]\text{.}\) The evaluation map induces a canonical bidual map \(A\to D_\omega D_\omega A\text{.}\) We call \(A\) \(\omega\)-reflexive when this map is an isomorphism. If a full subcategory \(\mathcal T_0\) is preserved by \(D_\omega\) and all its objects are \(\omega\)-reflexive, then \(\omega\) is a dualizing object for \(\mathcal T_0\).
