# 经典数学内容笔记的构建框架

初稿：2026-10-14。本文记录目前的写作理念与工作方法，供之后构建经典、基础性数学笔记时使用；遇到实际问题时继续补充、修改。

本框架讨论内容组织、定义与记号、证明深度、文献综合以及阅读体验。PreTeXt 的具体写法、版式与构建维护遵循 [笔记撰写与维护](../docs/note-authoring.md)。框架本身使用中文；网站数学正文沿用仓库目前的英文写作约定。

具体领域的范围、目录、读者背景与篇幅在各篇笔记中另行确定。本文件提供可调整的原则，不预先冻结所有笔记的结构。

## 1. 希望构建怎样的笔记

希望逐步形成一套能够长期阅读、查阅和扩展的个人数学笔记。它们应吸收过去优秀教材的组织与论证，也应随着新的理解、文献和实际使用不断改进。

主要目标是：

- **详尽**：在选定范围内充分交代概念、构造、假设、证明和边界，补足值得解释的省略步骤。
- **统一**：定义与记号在笔记内部保持一致；不同笔记讨论相同对象时，尽量采用兼容约定。
- **一般**：尽可能采用适用面广的定义与结果，并说明一般性所依赖的条件。
- **澄清**：解释不同文献中的异名、同名异义、不同归一化、不同假设与看似矛盾的陈述。
- **有理解**：保留自己的解释、例子、图示、反例和补充，使读者能理解构造的动机与作用。
- **可演进**：允许重写叙述、补充理论、修正错误、更新参考，以及适当地加入互动。

优秀教材是重要基础。笔记的价值来自有判断的整合、解释和持续修订，而不必要求每一部分都是原创。

## 2. 范围、读者与阅读路线

每篇笔记开始时，应对以下问题有一个暂定回答：讨论哪些问题，预设哪些背景，哪些内容要在本篇完整建立，哪些内容由其他笔记或外部文献提供。

范围可以在写作中调整。先有可工作的主线，再根据实际遇到的概念和文献差异增补；无需在动笔前穷尽全部目录。

内容的收录优先级取决于它对主题的作用：建立核心概念、完成关键构造、支持后续应用、解释重要分歧，或提供有用的边界与反例。参考书的章节安排与条目数量可用于查漏，收录范围仍由笔记的目标决定。

兼顾两种阅读方式：

- 顺序阅读时，定义、动机、构造和主要证明形成清楚的路线。
- 查阅时，读者能够快速找到采用的定义、精确条件、所需结论及对应来源。

较独立的主题可以单列章节或独立笔记，并标明需要调用的前置结果。章节之间可以有分支，不必强迫所有内容形成一条线性先修链。

## 3. 参考文献的选择与分工

优先使用可靠的教材、作者讲义、专著和原始文献。为每个主要主题选定承担组织与证明的主参考，再用其他来源比较定义、补充解释或核查遗漏。

各来源可以承担不同任务：有的适合构建主线，有的适合技术细节，有的提供更好的动机与反例，有的覆盖专门主题。无需对每个基础结果同时比较所有参考书。

引用应定位到实际使用的定义、命题、定理或证明。遇到关键推广、争议、历史归属或教材之间的实质分歧时，再追溯相应的原始来源。

核对文献时注意版本、勘误和正文中的全局约定。持续更新的资料应记录所用版本或核查日期；例如引用 Stacks 时保留稳定 tag，同时注意其陈述可能修订。

来源说明应出现在相关结果或论证附近。笔记自己的推广、改写、解释和推测也应能与来源中的结论区分。

### 择要吸收原文献中的重要观点

主动留意原文献中的重要观点，并根据笔记的主线与读者背景有所取舍地引入。值得保留的内容包括定义的动机、几何直观、证明策略、假设的作用、结果之间的联系、有启发性的例子、方法的局限和研究问题。以这些内容对理解论证和结果意义的帮助为取舍依据。

用笔记自身的语言重新组织，保留原文的适用范围、限定语和论述性质，并在使用处精确注明来源。区分原作者的观点、笔记自己的解释与后续文献的发展；涉及研究问题时，说明原文的时间背景，并核对后续进展。

影响主线理解的观点放在正文，简短解释可放旁注，较长的文献讨论放入注记、小节或附录。使选入的观点融入本篇叙述，并与已有定义、结果和论证建立清楚的联系。

## 4. 定义与记号的统一

先统一含义，再统一写法。为每篇笔记建立可供读者直接阅读的约定，并逐步整理术语与记号索引。共享宏可以减少重复，但数学含义仍需在正文中明确。

需要说明的通常包括：对象的类别、大小与有限性、底域或底环、态射方向、复合顺序、归一化，以及“自然”“典范”“唯一”等词的具体含义。

同一概念存在多种等价定义时，选取适合主线的一种作为本文定义，并在适当位置证明或引用等价性。若等价需要额外条件，应明确这些条件。

不同文献的概念实质不同时，保留区别并说明关系。不要通过替换名称或符号，把不等价的定义处理成同一个概念。

比较时把概念拆成实际可检验的条件。箭头方向相反但结构映射可逆，可能只是约定差异；去掉可逆性后则可能成为不同结构。分量逐一检测同构，也不能无条件替换成对这些检测取乘积。若书的勘误修改了定义，标明使用的是修订定义，并用简短例子说明与本文约定的关系。

跨笔记尽量保持相同含义的记号一致；确需局部约定时，在首次使用处说明。领域差异可以通过限定词、下标和文献对照表达，不必强求全站每个符号只有一种用途。

## 5. 怎样追求一般性

“尽可能一般”始终相对于本篇确定的理论范围。希望采用宽广且可准确使用的定义与结果，同时保留有价值的特殊情形。

一般性有多个方向：减弱假设、加强结论、允许更多对象、改善计算方式或减少证明依赖。它们可能需要不同取舍，并不存在总能合并成唯一最大版本的保证。

因此，重要结果可以保留一个主版本及若干有实际价值的变体，交代彼此的关系和采用理由。常用特例应容易识别，不能被一般陈述掩盖。

扩大文献中的定义或定理时，重新检查存在性、大小、自然性、选择以及证明中的每一步。新增推广需要单独承担证明责任。

固定宇宙或大小尺度时，特别核对原文中 “所有” 与 “小” 的范围：存在一个较大指标的极限，不表示只保小极限的函子也保持它；与小集合等势，也不表示原来的带标签集合本身属于该宇宙。可在正文采用便于使用的主版本，再用旁注解释重新编码、放大宇宙或更强保极限假设所得的变体。

若推广必须发展另一套理论，可明确调用那套理论的结果，或将其安排到独立笔记。一般性的追求应与主线的清楚程度一起考虑。

## 6. 陈述与证明的深度

详尽首先体现在定义准确、陈述完整、条件清楚与必要的文献辨析。证明按作用安排深度：例行推论可以用一两句话说明机制，成熟论证或支撑理论可以精确引用；有代表性、能解释关键方法的证明完整保留。笔记自己的推广或假设改动需要交代新增论证。关键假设、主要逻辑与非平凡构造应直接可见。

陈述需要准确表达量词、适用对象、存在条件和结论强度。全局约定可以减少重复，但应有明确的适用范围。

证明中特别注意：

- 构造是否与选择或表示方式无关。
- 对象层面的构造是否确实给出函子，映射是否自然。
- 所谓唯一性是严格唯一、唯一同构，还是其他意义。
- 空对象、空图式、有限与无限情形是否得到正确处理。
- 引用是否满足条件，证明之间是否存在循环依赖。

对于适合作为前置知识的标准事实，可以直接使用精确结论及来源；对于主线中的重要步骤，应在本篇证明，或明确指向另一篇完整论证。

不同证明揭示不同机制时，可以同时保留，例如一个说明泛性质，另一个提供显式计算。只有表达不同的重复证明可以适当压缩。

紧密相关的定义可以合并为一个带分项的定义条目，相近性质可以合并为一个带分项的命题，以减少零碎编号。尽量统一叙述模式：先说明对象与条件，再列定义或结论，随后给必要的辨析、例子与证明或引用。定义与命题保持各自的语义环境；合并以逻辑关联为依据，避免把无关内容堆成过长条目。

例子与反例也是理论的一部分。它们应帮助读者理解条件的作用、结论的边界，以及相近概念为何需要区分。

## 7. 正文、脚注、旁注与长补充的分工

积极使用脚注和旁注。这是同时保持主线连贯与文献比较详尽的重要方式。

| 位置 | 适合承担的内容 |
| --- | --- |
| 正文 | 本文定义、定理假设、主要构造、证明逻辑和必要依赖 |
| 脚注或旁注 | 异名与异义、文献记号翻译、假设作用、局部推导、直观、简短例子和精确来源 |
| 注记、独立小节或附录 | 较长的文献比较、替代证明、技术补充，以及适合整体查阅的约定 |
| 独立笔记 | 有自身问题、定义与定理体系，需要系统展开的支撑理论 |

每条旁注应解释一个具体位置的问题。读者跳过旁注时，仍应能够理解本文采用的定义、陈述和主要证明。

影响结论是否成立的差异，应在正文中明确；旁注可以进一步解释其原因。不能将关键假设或证明缺口隐藏在边栏中。

同名概念在其他领域有推广或不同含义时，首次定义可附一条范围说明。比如讨论模形式时，应交代本文采用的对象范围，并提示相关领域可能使用同名的更广对象；完整比较按需要放到专门位置。

旁注也需要承担数学准确性与来源责任。积累成一套独立理论的补充，应及时整理到合适的章节或另一篇笔记。

## 8. 支撑理论要有完整归宿

尽量减少“研究 A 的过程中，临时研究一段不深不浅的 B”。遇到需要的支撑理论，优先明确选择：作为已说明的先修知识、由独立笔记完整展开，或直接调用外部文献的精确结论。

例如，scheme 上同调笔记可以引用同调代数笔记，或直接调用所需定理。主线中应说明实际使用的条件与结论，完整的同调代数发展有自己的归宿。

跨笔记引用应让读者知道：

- 需要哪些定义与约定。
- 调用哪条结果，以及如何核对其假设。
- 得到怎样的结论；必要时包含自然性、兼容性或选择无关性。
- 到哪里查看完整证明。

独立笔记尚未完成时，可以先使用可靠的外部来源，无需等待整套基础体系建成才开始写作。

基础笔记中的定义和结果应保留稳定 ID 与链接。修改基础约定后，检查引用它的后续内容。具体跨篇链接与预览机制按工程能力逐步完善。

## 9. 个人理解、直观与互动

在准确理论的基础上，解释为什么引入一个定义、构造解决什么问题、证明的机制是什么，以及抽象表述如何对应熟悉的例子。

个人理解可以表现为重新组织的证明、一个更清楚的图示、具体计算、条件的反例、不同观点的联系，或对常见误解的澄清。解释性类比应注明适用范围，猜测与未完成的推广也应明确标识。

互动适合用于探索具体构造、改变假设、观察反例或检查有限样本。每个组件应帮助读者解决明确的理解问题，并配有可独立阅读的文字解释。

有限演示、计算验证和一般证明应区分。互动可以增强理解，普遍结论仍须有相应论证。根据内容需要逐步增加互动，不要求每节都配组件。

## 10. 一个可调整的工作过程

1. 写下本篇的目标、读者、暂定范围、前置知识与几项关键约定。
2. 选定主参考，拟一份能开始工作的目录，并标出支撑理论的来源。
3. 试写一个完整主题，将定义、构造、证明、例子、旁注与引用一起完成。
4. 用试写遇到的实际问题调整记号、范围与叙述方式，再扩展其他部分。
5. 对重要陈述比较来源、核对假设，补齐主线中需要的证明；将较长支撑理论移到完整归宿。
6. 检查阅读路线与查阅路径，整理索引、文献对照及跨篇引用。
7. 在实际阅读和应用中持续修订，并把值得复用的新经验写回本框架。

写每章时，可以简短说明本章回答的问题、需要的背景和主要参考。概念较多时，再增加章节之间的关系说明。

审稿时重点问：采用的定义是否明确，文献差异是否如实处理，假设是否足够，证明是否可核查，外部依赖是否精确，以及读者能否沿主线读完。

这些记录可以先放在普通文字、注记或简单表格中。范围、来源数量、旁注长度和记录格式均可根据实际写作调整。

## 11. AI 辅助与长期维护

AI 可以承担检索与对照、起草、表达统一、补充例子与反例、检查引用和依赖，以及图示与互动制作，从而使更细致的整理成为可接受的工作量。

核心定义的取舍、重要推广和证明仍需要可追溯的核查。多个回答一致、链接存在或构建成功，都不能单独确认数学内容正确。

草稿中允许记录“待核对”“待补证明”“暂定约定”等状态；尚未核实的说法应与已建立结论区分。核查记录的详细程度随问题的重要性调整。

后续修订尤其注意：

- 新文献或勘误是否改变已有陈述。
- 修改定义或记号后，哪些证明与后续笔记受到影响。
- 对话中得到的解释是否值得补入对应正文或旁注。
- 新的反例、替代证明与互动是否改善理解。

重要修订留下简短记录，保留可追溯的来源与稳定链接。文献比较表、结果状态与依赖记录可以逐步建立，不必一开始采用复杂系统。

## 12. 当前范畴论讨论提供的一个应用例子

目前普通 1-范畴论笔记的方向，是围绕范畴、函子和自然变换，系统组织 Yoneda、极限与余极限、共尾与滤过、伴随、Kan 延拓、密度、局部化、Ind/Pro、单子等内容；进一步主题的范围之后再定。

这篇笔记优先采用集合、偏序和代数对象的例子。预层先作为集合值反变函子处理；拓扑、层与拓扑斯、高阶范畴、加性及同调理论等在确有需要时转介独立笔记。

以上是本次范畴论笔记的范围取舍，不是其他领域笔记的普遍限制。此前讨论的目录与书目是候选方案，实际章节和参考分工继续随写作修订。

可用的来源池包括李文威《代数学方法》、Kashiwara–Schapira、Stacks、Mac Lane、Borceux 与 Riehl；可达与可展示理论、端与余端等主题再按需要调用专门文献。
