# Topic plans

[Project entry](../README.md) · [Writing guides](../prompts/README.md) · [Notes implementation](../docs/note-authoring.md)

These documents preserve the author's topic plans and reference maps. Planning may be in Chinese; published mathematical notes use English. Plans are working context for the corresponding topic and can be revised as the material develops.

- [Classical mathematical notes framework](classical-notes-framework.md): the earlier general framework, retained as background alongside the current writing guides.
- [Enumerative geometry](enumerative-geometry/README.md): proposed note allocation, chapter routes, and supporting reference maps.
- [Homological algebra](homological-algebra/README.md): chapter allocation and source roles.
- [Sheaf theory](sheaf-theory/README.md): scope and division of the four planned notes.

Historical wording such as “this round remains local” records the original task context. The current user request controls the work and publication authorization. Read the relevant plan rather than treating every plan as a global requirement.

Keep ongoing note-specific decisions in the note's `brief.md`, linking to the relevant plan. The catalog remains the authority for build settings and listing choices.
